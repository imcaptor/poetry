# 近体诗技能验收清单

## 一、触发与路由

- `SKILL.md` 的中文 description 能触发五绝、七绝、五律、七律、平水韵、平仄、对仗、步韵和旧作修改。
- 主文件只保留总原则、分支和完成标准，不重复专题细则。
- 创作分支读取 `poetics/README.md`、`poetics/创作流程与章法.md`、`forms/格律模板.md`、`forms/用韵检查.md`。
- 只有律诗任务读取 `forms/律诗对仗.md`。
- 只有偏离正格、孤平或拗句时读取 `forms/变格与拗救.md`。
- 只有多音、古今音或同部异音不明时读取 `forms/韵部疑难.md`。
- 只有精修和深度点评读取 `poetics/炼字用典与禁忌.md`、`poetics/poem-illnesses.md`。
- 只有研读、引用或核原文时读取 `corpus/沧浪诗话选录.md`。
- `forms/jintishi.md` 仅作兼容入口，不再默认加载。

## 二、完成标准

- 裸请求最多追问三个问题，缺信息时按默认继续。
- 新作先定体裁、起式、入韵方式、韵部和完整模板，再填诗。
- 默认三版为雄浑、自然、沉著。
- 每个可见候选均运行 `tools/check-meter.mjs`；硬伤未修不展示。
- 脚本通过后仍人工检查挤韵、重字、同音和同部异音。
- 孤平是硬伤；合法拗救标「变格·合法」，不机械判错。
- 律诗检查颔联、颈联对仗及四联推进，改联后必须放回全诗复读。
- 格律通过后做诗病自检；不以小病机械淘汰有诗意的句子。
- 候选阶段不查重；定稿或作者主动要求时逐句查重。
- 多音、古今音或工具冲突标「需人工确认」。
- 评读唐诗不得用后出的平水韵机械倒推裁判。
- 定稿按 `workflows/archive.md` 建档。

## 三、渐进式披露检查

- 纯格律校验不加载诗话全文、炼字专题和归档协议。
- 普通七绝创作不加载律诗对仗文件。
- 正格稿无争议时不加载变格与韵部疑难文件。
- 同一规则不得同时在主文件、专题文件和多个 README 重复维护。
- 所有新增正文与专题文件名使用中文；系统约定的 `SKILL.md` 和脚本名除外。

## 四、冒烟场景

- 「帮我写一首七绝」：最多三问，随后给已过格律的三版和报告。
- 「按平水韵改这首五绝」：先列硬伤，再给保留原意的最小改动版。
- 「用 cnkgraph 验这首七律」：运行脚本，检查中二联、挤韵和疑难字。
- 「这句是否孤平」：有疑问时运行 `tools/check-guping.mjs`，并区分未救孤平与合法拗救。
- 「把颔联改工整」：不得只交两句，须放回全诗复查气脉。
- 「查严羽原文」：才读取 `corpus/沧浪诗话选录.md`。
