# 近体诗技能验收清单

用 writing-great-skills 检查此技能时，至少确认下面四项。

## 1. 触发

- `SKILL.md` 的 description 负责触发诗歌任务，不把近体诗全部细则塞进 description。
- 近体诗触发词能稳定指向 `forms/jintishi.md`。
- 需要格律校验时，优先指向 `tools/cnkgraph-meter-checker.md` 和 `tools/check-meter.mjs`；需要搜韵式复核时，才指向 `tools/souyun-checker.md`，且不声称内置私有搜韵数据。

## 2. 信息层级

- 通用诗歌规则留在 `SKILL.md`。
- 近体诗范围、流程、格律报告留在 `forms/jintishi.md`。
- cnkgraph 格律接口、字段映射、脚本调用流程留在 `tools/cnkgraph-meter-checker.md`。
- 搜韵边界、字段映射、外部复核流程留在 `tools/souyun-checker.md`。
- 平水韵映射、格律表、典故库、样例和反例后续分别进入对应窄文件，不回填到 `SKILL.md`。
- 诗病自检留在 `poetics/poem-illnesses.md`；主流程只引用，不把 54 种禁忌逐条塞进 `SKILL.md`。

## 3. 完成标准

- 裸请求最多追问 3 个问题；缺信息时用默认继续。
- 创作必须先定体裁、起式、韵部和模板，再填诗。
- 默认三版候选风格为雄浑、自然、沉著；不再使用清雅含蓄、沉郁顿挫、新意峭拔作为固定三分法。
- 输出前必须运行 `tools/check-meter.mjs` 做格律校验；严格合律新作的硬伤未修不能交最终稿。修改旧作时若修律会损伤诗眼，须保留原句、给出合律备选并说明取舍，不得擅自以律害意。
- 孤平是硬伤；五言或七言平收句除韵脚外只剩一个平声字时，必须改到无孤平，不能用“一三五不论”放过。
- `tools/check-meter.mjs` 返回孤平、平仄或出韵硬伤时，必须先提醒作者，再修改并复校；模型判断孤平不稳或被用户指出风险时，可再用 `tools/check-guping.mjs` 按平仄串复核。
- 律诗必须检查颔联、颈联对仗。
- 律诗须先定四联推进关系，再一气写成八句初稿；不得逐句、逐联拼装。颔联和颈联除对仗外，必须各生新意并推动全篇，不能合掌或原地铺排。
- 每次炼字、改句或磨对仗后须通篇吟诵；局部虽工而导致承接断裂、情绪停滞或句势变弱时，应恢复原句或重构全联，以全篇气脉为先。
- 有多音、古今音或外部工具冲突时，标“需人工确认”。
- 候选稿不运行 `tools/check-similar.mjs`；定稿前或作者主动要求时必须查重。
- 格律通过后应做诗病自检；明显凑韵、合掌、义理断裂、无意重字重意优先修改，轻微或有意诗病标为可商榷。
- 评读唐诗时不得用宋金时期形成并定型的平水韵机械倒推裁判；须结合唐代语音、当时韵书、传统变格和具体诗例。
- 每次修改先判断意象、诗眼与气脉，再区分严重出律和轻微争议；用户明确要求完全合律时，既守指定格律，也不得交付虽合律却损害诗意的句子。

## 4. 精简

- 同一规则只放一个权威位置；不要在多个 README 重复维护。
- 删除不改变行为的解释性句子。
- 搜韵相关内容只保留合法接入边界与复核协议，不沉积抓取、缓存或私有数据复制说明。

## 冒烟提示

- “帮我写一首七绝。” 应触发最多三问，随后按默认流程写三版并给完整格律报告。
- “按平水韵改这首五绝。” 应优先保留原意原字，先列硬伤，再给最小改动版。
- “用 cnkgraph 验一下这首七律。” 应运行 `tools/check-meter.mjs`，列出硬伤和需人工确认项。
- “用搜韵验一下这首七律。” 在没有用户提供结果或授权工具时，应先运行 `tools/check-meter.mjs`，并列出建议人工复核项。
- “这首唐诗按平水韵出韵，是否不合格？” 不得直接判不合格；应说明平水韵后出，并回到历史音韵与诗例判断。
- “改成合律后诗眼没了。” 应恢复或保留原句，同时给合律备选和取舍说明，由作者决定。
- “万时一梦轻”若标为 `仄平仄仄平`，`tools/check-guping.mjs` 必须判为孤平且返回不通过。
- “把这首七律的颔联改得更工整。” 不得只交两句局部改稿；须把改句放回全诗，复查颔联承接首联、颈联能否由此转深以及全篇吟诵是否断气。
