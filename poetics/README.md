# 诗学

这个目录用于审美校准：此技能应写出、珍视、警惕并朝向哪种诗。

好的条目应足够具体，能改变逐行层面的判断。

## 审美总纲

### 自然为上

「不尚清奇尚自然」——宁可平实自然，不可刻意求奇。雄浑、自然、沉著都是手段，不是目的。如果为了追求某种风格而牺牲真意，宁可放弃风格。三版候选默认按《二十四诗品》取法：雄浑、自然、沉著；它们是工具箱，不是枷锁。

### 得意以忘相

诗品如佛之三十二相，惟得意以忘相。理解各种风格是为了超越风格，不是机械套用。下笔时不要被「我要写雄浑」「我要写沉著」框住——诗有自己的生命，让它长出来，不是捏出来。

### 平实无华，字字自心底涌出

好诗的字是涌出来的，不是挤出来的。纵多有譬喻引用，不觉其艰涩。比喻、典故可以有，但读起来不能让人觉得累、觉得隔。凡让读者觉得诘屈聱牙的句子，退回去重写。不以诘屈聱牙为上，天地已变，与天地众生通者，方能与众生共参。

### 真正的悲慨

写悲慨不是宣泄情绪，不是呐喊控诉。真正的悲慨，如观众生如幻，观一切无常，而依然慈悲。写时代之痛，力量来自克制而非声量。看透了还在写，这本身就是悲慨。

### 艺品即人品

在最高处，艺品与人品浑然合一。诗的高下最终取决于写诗的人——不是技巧，是胸襟、是学养、是对世界的真诚。格律可以学，意象可以磨，但诗里有没有一个真实的人，骗不了读者。拿修道修心的法门用之于艺术，叫杀鸡用牛刀；艺术之道亦可用于修道修心，叫艺虽小道亦有可观。

### 两忌三避（许清泉）

写诗有**两忌**：**忌俗、忌熟。** 俗是俗气、俗套，熟是熟词、熟路。俗词堆砌、熟句顺手拈来，都是偷懒，不是写诗。

**三避**：**一避古人，二避今人，三避自己。**
- 避古人：不要在诗里看见李白、杜甫、苏轼的影子。句式、节奏、转折方式不能蹈袭前人。偷语、偷意、偷势，皆为大忌。
- 避今人：不要模仿当代名家的风格和套路。
- 避自己：不要重复自己写过的句子、用过的意象、走过的路数。每一首诗都应该是新的。

"取法于上，仅得其中；取法于中，不免为下。"对自己严些没有坏处。

**自检：** 写完一首诗，逐句问——这一句在哪里见过？这个意象自己以前用过吗？整体结构像谁的？如果答得上来，就重写。

### 与众生共参大道

诗的终极指向不是个人抒怀，是与天地众生相通。诗言志、兴观群怨，乃茫茫大道之演化，可参天地之化育。写诗不止是自己的事，是与众生共参的事。有此发心，诗才有大气象。
