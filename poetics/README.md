# 诗学

这个目录用于审美校准：此技能应写出、珍视、警惕并朝向哪种诗。

好的条目应足够具体，能改变逐行层面的判断。

## 审美总纲

### 自然为上

「不尚清奇尚自然」——宁可平实自然，不可刻意求奇。雄浑、自然、沉著都是手段，不是目的。如果为了追求某种风格而牺牲真意，宁可放弃风格。三版候选默认按《二十四诗品》取法：雄浑、自然、沉著；它们是工具箱，不是枷锁。

### 得意以忘相

诗品如佛之三十二相，惟得意以忘相。理解各种风格是为了超越风格，不是机械套用。下笔时不要被「我要写雄浑」「我要写沉著」框住——诗有自己的生命，让它长出来，不是捏出来。

### 平实无华，字字自心底涌出

好诗的字是涌出来的，不是挤出来的。纵多有譬喻引用，不觉其艰涩。比喻、典故可以有，但读起来不能让人觉得累、觉得隔。凡让读者觉得诘屈聱牙的句子，退回去重写。不以诘屈聱牙为上，天地已变，与天地众生通者，方能与众生共参。

### 真正的悲慨

写悲慨不是宣泄情绪，不是呐喊控诉。真正的悲慨，如观众生如幻，观一切无常，而依然慈悲。写时代之痛，力量来自克制而非声量。看透了还在写，这本身就是悲慨。

### 咏史悲剧：以事象承痛，慎用口号

咏亡国、战乱、山河之痛时，先让可感的事象承住重量：天候、地势、兵势、人物动作、遗物与后果。不要把“惨”“恨”“耻”“不知羞”等结论、辱骂或密集感叹直接堆进诗里；判断可以有，但须由史事与具体物象生出。

**自检：** 删去抽象判断和感叹词后，悲剧是否仍可被看见、听见？若不能，退回场景与动作重写。结句宜留余痛，不作口号式断言。

### 艺品即人品

在最高处，艺品与人品浑然合一。诗的高下最终取决于写诗的人——不是技巧，是胸襟、是学养、是对世界的真诚。格律可以学，意象可以磨，但诗里有没有一个真实的人，骗不了读者。拿修道修心的法门用之于艺术，叫杀鸡用牛刀；艺术之道亦可用于修道修心，叫艺虽小道亦有可观。

### 境随心转：作者须在场

忌铺陈意象太多，唯独没有作者自己。诗中之境不是静物陈列，而是作者心灵的投射；人可以不直说、不露面，却须使所见、所取、所感皆有其心意的来处。写景时先问：**为何偏偏看见此物、此刻？它照见了什么？** 若换任何人都能如此罗列，便还只是材料，尚未成境。

**自检：** 删去题目与署名后，此诗是否仍能读出一个具体的人在看、在经历、在取舍？若只剩风花云月的排列，须回到作者的动作、视角、心事或判断，重定一两处落点；不可另加空泛抒情来补“我”。

### 两忌三避（许清泉）

写诗有**两忌**：**忌俗、忌熟。** 俗是俗气、俗套，熟是熟词、熟路。俗词堆砌、熟句顺手拈来，都是偷懒，不是写诗。

**三避**：**一避古人，二避今人，三避自己。**
- 避古人：不要在诗里看见李白、杜甫、苏轼的影子。句式、节奏、转折方式不能蹈袭前人。偷语、偷意、偷势，皆为大忌。
- 避今人：不要模仿当代名家的风格和套路。
- 避自己：不要重复自己写过的句子、用过的意象、走过的路数。每一首诗都应该是新的。

"取法于上，仅得其中；取法于中，不免为下。"对自己严些没有坏处。

**自检：** 写完一首诗，逐句问——这一句在哪里见过？这个意象自己以前用过吗？整体结构像谁的？如果答得上来，就重写。

### 与众生共参大道

诗的终极指向不是个人抒怀，是与天地众生相通。诗言志、兴观群怨，乃茫茫大道之演化，可参天地之化育。写诗不止是自己的事，是与众生共参的事。有此发心，诗才有大气象。

## 沧浪诗话要则（严羽·摘要）

原文存 `corpus/沧浪诗话选录.md`，仅研读、引用或深度点评时加载；日常创作只用以下要则：

1. **入门须正，取法乎上。** 以汉魏晋、盛唐为法；学其上仅得其中，莫从低处取法。
2. **诗贵兴趣与情性。** 不以文字、才学、议论为诗；言有尽而意无穷。
3. **先除五俗。** 俗体、俗意、俗句、俗字、俗韵，皆须避。
4. **语意须有余味。** 语忌直，意忌浅，脉忌露，味忌短；音韵忌散缓与迫促。
5. **下字贵响，造语贵圆。** 用字有声韵质感，句子圆融自然，不见拼接。
6. **起结最见功力。** 发端忌作态；结句贵能收住全篇、留下回响。
7. **不必太着题，不必多使事。** 典故、押韵皆以自然合诗为先，不为考据而伤兴致。
8. **须参活句，勿参死句。** 不机械填格，不偷语、偷意、偷势；词气可起伏，不可乖戾。
9. **先看气象，再看工拙。** 盛唐有似粗似拙而非粗拙的浑成；求雄浑悲壮，不求笔力外露的“健”。
10. **绝句尤宜克制。** 绝句难于律诗，五绝又难于七绝；篇幅越短，越要字字有用、余韵长。
