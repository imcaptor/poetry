# 格律报告

每次都完整展开格律报告。至少包括：

- **模板锁定过程（必须写在报告第一行，不得省略）：**
  1. 首句第二字 → 平/仄 → 起式
  2. 首句末字 → 平/仄 → 是否入韵
  3. 锁定模板名称
  这一步是防错硬步骤，写出来才能防止凭感觉选错模板。
- 体裁、格律模板、起式、用韵标准、韵部。
- 每句平仄标注。
- 每句韵脚、韵部、是否押韵。
- 问题点：孤平、三平尾、失粘、失对、出韵、对仗不工等。
- 律诗中二联对仗说明。
- 多音、古今音差异、疑难字的"需人工确认"标注。

如果某一句不稳，给 3-5 个可替换字或短语，并说明各自影响。

## 孤平判定流程（防误判硬规则）

孤平是最容易误判的格律问题。以下流程**必须严格执行**，不得跳步：

1. **孤平只可能出现在平收句**（末字为平且押韵的句子）。仄收句不存在孤平，直接跳过。
2. 平收句中，逐字标注实际平仄，与正格模板逐位对照。
3. 发现某字偏离正格（该平用仄）时，**不得立即判定孤平**。必须先数清该句中**除韵脚外的所有平声字数量**。
4. 除韵脚外仍有**两个或以上**平声字 → **不是孤平**，属于一三五不论的合法灵活。
5. 除韵脚外只剩**一个**平声字 → 疑似孤平，此时仍须继续检查：该句是否存在**本句自救**（五言第三字、七言第五字用平声补救）。
6. 存在拗救 → **合法变体**，标注"拗救·合法"，不列硬伤。
7. 无拗救 → 确认为孤平硬伤，必须修改后复校。

**典型误判案例（引以为戒）：**

"是佛是仙诚不欺" = 仄仄仄平平仄平，模板为"仄仄平平仄仄平"。
- 第三字"是"为仄（偏离正格）
- 但第五字"诚"为平（已拗救）
- 除韵脚"欺"外，有"仙""诚"两个平声字
- 结论：**不是孤平**，拗救合法 ✅
- 错误判定：只看第三字变仄就判孤平，未检查第五字是否已救 → **严禁此类跳步判断**

## 完成标准

报告必须让作者看见：哪项通过、哪项是合法变格、哪项需人工确认、哪项必须修改。定稿阶段另加逐句查重结果。
