# 格律与诗体

本目录只保存近体诗的形式规则，并按任务渐进加载：

- `格律模板.md`：四体正格；所有创作、修改和校验任务读取。
- `用韵检查.md`：押韵、挤韵、重字、同音与孤雁；每个候选读取。
- `变格与拗救.md`：孤平、拗救、三仄尾及正格/变格；仅在偏离正格或用户问变格时读取。
- `韵部疑难.md`：同部异音、多音和易错字；仅在音韵不明时读取。
- `律诗对仗.md`：五律、七律的中二联与四联气脉；仅律诗任务读取。
- `格律报告.md`：校验报告字段；需要完整报告时读取。
- `jintishi.md`：旧引用兼容入口，不再承载全部规则。

同一规则只在一个专题文件中维护。
