# 中文近体诗技能

本技能只处理五绝、七绝、五律、七律的创作、修改、评析和格律校验，默认使用平水韵。

## 渐进式结构

- `SKILL.md`：触发、总原则和任务路由。
- `forms/`：正格模板、用韵、变格、韵部疑难、律诗对仗和报告格式。
- `poetics/`：短审美总纲、创作章法、炼字用典和诗病。
- `tools/`：格律、孤平与查重脚本及调用协议。
- `workflows/`：定稿归档流程。
- `corpus/`：诗话原文和语料，只按需研读。
- `tests/`：结构与行为验收清单。

## 维护原则

1. 同一规则只放一个权威位置。
2. 每次任务只读取当前分支需要的文件。
3. 原文语料不进入日常创作上下文，只保留短摘要。
4. 新增规则先判断归属，不继续堆入 `SKILL.md` 或兼容入口。
5. 每次新作在 workspace 根目录 `jintishi/YYYY-MM-DD-诗名/` 建档；具体作品不写回技能。
