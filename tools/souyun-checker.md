# 搜韵式格律校验接入规则

## 定位

搜韵类工具是近体诗格律、押韵、诗词资料检索的成熟参照。这个技能可以把它作为外部复核环节，但不要声称已经“内置搜韵”或复制了搜韵 APP / 网站的私有校验库。

可内置的是工作流、字段映射、人工复核规范，以及用户合法提供的查询结果；不可内置未经授权抓取或复制的搜韵数据库、页面内容、接口返回。

## 何时使用

以下场景优先做搜韵式复核：

- 用户明确要求“按搜韵检查”“用搜韵验一下”。
- 作品准备交最终稿，需要比普通自检更稳。
- 出现多音字、入声字、古今音差异、韵部争议。
- 步韵、和诗、限韵、律诗对仗等高约束任务。

## 合法接入方式

按优先级选择：

1. 用户提供搜韵 APP / 网站的校验截图、文字结果或导出内容：读取并转写为复核意见。
2. 用户提供明确授权的 API、数据文件或本地工具：按其许可范围调用。
3. 没有授权工具时：执行本技能的本地规则校验，并把疑难项列为“建议用搜韵人工复核”。

不要自动绕过登录、批量抓取页面、复制韵书库，或把搜韵结果缓存成可复用数据库。

## 复核流程

1. 先按 `forms/格律模板.md`、`forms/用韵检查.md` 生成或修订作品。
2. 做本地自检：体裁、句数、字数、平仄、押韵、粘对、孤平、三平尾、拗救、律诗对仗。
3. 如果有搜韵结果，把结果拆成结构化字段：
   - 原句。
   - 平仄标注。
   - 韵脚与韵部。
   - 出韵、失替、失对、失粘、孤平、三平尾、拗救提示。
   - 多音或争议字。
4. 对比本地自检与搜韵结果：一致项直接确认；冲突项标“需人工确认”，并说明冲突点。
5. 修稿时优先修硬伤：出韵、失律、孤平、三平尾、律诗中二联不对仗。
6. 修完后再跑一轮本地自检；仍有争议时不要假装通过。

## 输出要求

格律报告中增加“外部复核”小节：

- `未接入搜韵结果`：说明已做本地自检，并列出建议人工复核的字或句。
- `已参考用户提供的搜韵结果`：列明一致项、冲突项、已据此修改的地方。
- `已调用授权工具`：写明工具名、输入范围、关键结论；不要泄露密钥或内部接口细节。

示例措辞：

> 外部复核：当前未直接接入搜韵数据库；本稿已按平水韵与近体诗规则自检。第 2 句“看”涉及古今音/多音差异，建议用搜韵再人工确认。

## 后续可开发的适配器

如果将来有合法数据源或 API，可以新增 `tools/` 下的适配器说明或脚本，输入输出保持以下 JSON 形状：

```json
{
  "poem": ["句一", "句二", "句三", "句四"],
  "form": "七绝",
  "rhyme_standard": "平水韵",
  "expected": {
    "rhyme_group": "上平一东",
    "pattern": "平起入韵"
  },
  "result": {
    "line_checks": [],
    "rhyme_checks": [],
    "warnings": []
  }
}
```

适配器只能封装用户有权使用的工具；结果要在最终报告里标明来源和不确定项。
