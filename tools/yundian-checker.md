# 韵典接入规则

## 定位

韵典（ytenx.org）是综合韵书查询工具，包含《广韵》、《中原音韵》、《洪武正韵牋》、《分韵撮要》和《上古音系》，可查询汉字的声母、韵部、声调、反切等音韵信息。

本工具用于在近体诗创作中逐一验证每个字的平仄和韵部归属，确保不凭现代汉语语感误判。

## 何时使用

**每一次近体诗创作和校验，都必须调用韵典逐字查音辨韵。** 以下场景特别需要：

- 拟定韵部之后，确认每个韵脚字确实属于该韵部
- 多音字、古今音差异字、入声字、易错字的平仄判定
- 挤韵检查：确认非韵脚处没有出现与韵脚同韵部的字
- 拗救方案的声调验证

## 接入方式

**通过 web_fetch 查 ytenx.org 检索页：**

```
https://ytenx.org/zim?q={URL编码的汉字}
```

ytenx.org 返回 HTML 搜索结果页面，其中包含：

- 该字在《广韵》中的反切、声母、韵部、开合、等次、声调
- 该字在《中原音韵》中的读音
- 该字在《洪武正韵》中的读音
- 该字在《分韵撮要》中的读音
- 该字在《上古音系》中的拟音

## 工作流程

### 步骤 1：逐字查询

对诗中每个字（不是仅仅易错字），逐一调用 web_fetch 查询 ytenx.org。URL 格式：

```
https://ytenx.org/zim?q={URL编码的单个汉字}
```

### 步骤 2：提取韵部和平仄

从 ytenx.org 返回结果中，对每个字提取：

| 字段 | 说明 | 判定平仄 |
|------|------|----------|
| 广韵·声调 | 平声/上声/去声/入声 | 平声=平，其余=仄 |
| 广韵·韵部 | 如东韵、支韵、真韵等 | 用于韵脚校核和挤韵检查 |
| 广韵·反切 | 如「书之切」 | 辅助确认读音 |

**声调 → 平仄映射规则：**

- **平声（上平、下平）** → **平**
- **上声** → **仄**
- **去声** → **仄**
- **入声** → **仄**（特别注意：普通话中已消失的入声字，在平水韵中仍是仄声）

### 步骤 3：汇总校验

将每字平仄逐字列出，对照格律模板逐句校验。对多音字和古今音差异字，标注「需人工确认」。

### 步骤 4：韵脚校核

对每个韵脚字，提取其广韵韵部，确认所有韵脚字是否属于同一韵部（或允许的邻韵）。如果某韵脚字韵部偏离，标注「出韵」或「孤雁出群/入群」。

### 步骤 5：挤韵检查

对全诗每个非韵脚位置的字，检查其广韵韵部是否与韵脚韵部相同。如果相同，标注「挤韵」并建议替换。

## 输出格式

格律报告中增加「韵典核查」小节：

```
【韵典核查】
  逐字平仄（ytenx.org 广韵数据）：
    句①：山（生母·山韵·平声→平）光（见母·唐韵·平声→平）...
  
  韵脚校核：
    韵脚①「山」：广韵·山韵·平声 ✅ 同部
    韵脚②「闲」：广韵·山韵·平声 ✅ 同部
    结论：全诗押山韵，韵脚同部 ✅
  
  挤韵检查：
    句①非韵脚「间」：广韵·山韵·平声 → ⚠️ 挤韵（与韵脚同属山韵）
    其余非韵脚字：无挤韵
  
  需人工确认：
    - 句②「看」：广韵平/去两读，「看守」平声、「看见」去声
```

## 注意事项

1. **ytenx.org 基于广韵，不是平水韵。** 广韵 206 韵，平水韵 106 韵。如遇广韵韵部超出平水韵范围，需要将广韵韵部映射到平水韵部。

2. **一个字可能有多个广韵读音。** 需要根据诗意判断使用哪个读音。

3. **不要因为查韵典拖慢整体创作节奏。** 草稿阶段可以先初步标注平仄，定稿阶段再逐字查韵典复核。但最终报告必须包含韵典核查结果。

4. **韵典查询结果不确定时，不能含糊。** 标注「需人工确认」并说明原因，不要强判。

## 与现有工具的衔接

- `tools/check-similar.mjs`：定稿查重（诗文库/cnkgraph）
- `tools/check-guping.mjs`：孤平硬规则校验
- `tools/yundian-checker.md`（本文件）：逐字查音辨韵（韵典/ytenx.org）

三个工具的调用顺序：先自检平仄 + 韵典逐字查音，再校孤平，最后查重。韵典应在「校硬伤」阶段调用。
